# ما يتشاركه النموذجان فعلًا — القسم 3

سألتَ: هل يشترك النموذجان في موضوعات أو أسئلة؟ الجواب في طبقتين.

## التكرار النصّي: صفر

| | متطابق | متشابه ≥ 0.82 |
|---|---|---|
| داخل المشتريات | 0 | 0 |
| داخل المالي | 0 | 0 |
| **عابر بين النموذجين** | **0** | **0** |

ما يتكرر داخل كل نموذج تكرار **بنيوي مقصود**: الأسئلة المشتركة لكل مرحلة
(presence، owner، approver…) ×12، والأسئلة الموحدة الأربعة ×167 متطلبًا.

## التداخل المعنوي: موجود، وهذا موضعه

لا يُكتشف بالنص لأن النموذجين يسألان الحقيقة نفسها بألفاظ مختلفة. فُتح كل موضع
يسمّيه القسم 3 وقُرئ:

| الموضوع | المشتريات | المالي | الحكم |
|---|---|---|---|
| **المطابقة** | `INV/matching` «مع أي مستندات تُطابَق الفاتورة؟» | `FIN-038` «متى تُقبل فاتورة المورد وكيف تُطابق مع الأمر والاستلام؟» | **تداخل صريح** — السؤال نفسه |
| **حجز الموازنة** | `BUD/reserve` «هل يُحجز المخصص عند الالتزام؟» | `FIN-019` «كيف تُحتسب الالتزامات القائمة ضمن الرصيد المتاح؟» | **تداخل صريح** |
| **الحساب البنكي للمورد** | `VEN/bank` «كيف يُتحقق من تغيير الحساب البنكي؟» | `FIN-036` «كيف يُنشأ المورد وتُراجع بياناته… والبنكية؟» | **تداخل صريح** |
| **تجديد العقد** | `ORD/renewal` «هل يُتابَع التجديد التلقائي؟» | `FIN-037` «كيف تُتابع العقود… والمدد والكميات المتبقية؟» | تداخل جزئي |
| **فصل المهام** | `GOV/sod` «هل يتولى التنفيذ والمراجعة والاعتماد أشخاص مختلفون؟» | `FIN-004` و`FIN-005` بجدول الصلاحيات الكامل | تداخل: المالي يملك المصفوفة، والمشتريات تسأل سؤالًا أضيق |
| **حدود الاعتماد** | `AWD/criteria` أساس الاختيار · `ORD/commitment` مستند التوثيق | `FIN-035` جدول حدود الاعتماد | **لا تداخل فعلي** — المستند يقرن الموضعين، والأسئلة مختلفة. الحدود في المالي وحده |

## ما لا أقرره

المستند صريح: «يُحسم مالك كل حقيقة مشتركة مع صاحب المالية والمشتريات، ثم تُضاف
الروابط». ولا تُدمج سجلات إجابة لتشابه الموضوع:

> «لا تُحذف المتطلبات المتشابهة لمجرد تشابه الاسم. تُدمج الحقيقة المشتركة في
> مصدر واحد، وتُحفظ المعالجة المتخصصة لكل وظيفة.»

فالمطابقة مثلًا: المالي يملك معالجة الفروق والحسابات، والمشتريات تملك مستندات
الاستلام — ويبقى السؤال مرة واحدة بمصدر واحد. أيُّهما المصدر؟ قرار صاحب العملية.

وحتى يُحسم، الأسئلة الستة أعلاه تُسأل مرتين في نموذجين، وقد تُجاب إجابتين
مختلفتين دون أن يشكو شيء — وهو ما يحذّر منه معيار القبول LINK01.

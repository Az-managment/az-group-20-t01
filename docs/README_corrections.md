## ما بقي غائبًا بعد قراءة كل حقول المرحلة

قُرئت مراحل REQ وVEN وRCV حقلًا حقلًا، لا بحثًا. والغائب أربعة، أُضيفت:

| المرحلة | المفتاح | السؤال |
|---|---|---|
| REQ | `purchase_type` | الطلب ده شراء إيه؟ — سلع، أصول، خدمات، أعمال ومقاولات، اشتراكات |
| REQ | `purchase_route` | هيتم الشراء بأي مسار؟ — منافسة، أمر مباشر، مورد وحيد، طارئ، اتفاقية إطارية |
| REQ | `request_fields` | الطلب بيحمل إيه قبل ما يتبعت؟ — المواصفات، الكمية، وحدة القياس، تاريخ الاحتياج، الجهة المستفيدة |
| VEN | `duplicate` | إزاي بتمنعوا تسجيل نفس المورد مرتين؟ — بالرقم الضريبي أو السجل التجاري |

الأول والثاني ينفذان DEV07 حرفًا: «افصل نوع الشراء عن مساره». والثالث يفصل بيانات
الطلب عن سؤال «مين يحدد المواصفات؟» القائم. والرابع يميّز تكرار **المورد** عن تكرار
**الفاتورة** (`INV/duplicate`) وتكرار **الدفع** (`PAY/duplicate`) وكلاهما قائم.

**صياغتها مسودة** تنتظر اعتماد صاحب العملية. الموضع والمفاتيح هي ما ثُبّت.
